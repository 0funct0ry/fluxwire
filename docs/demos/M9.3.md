# M9.3 demo

1. Build the dev host: `cargo build -p fluxwire --features dev-mcp,runtime-shaders` (drop `runtime-shaders` if the Metal toolchain is installed).
2. Start the app with a socket: `target/debug/fluxwire --mcp-socket /tmp/fw.sock fixtures/payments-api`. The window opens on the Workspace and stderr prints `fluxwire: mcp socket /tmp/fw.sock`.
3. `ls -l /tmp/fw.sock` shows `srw-------`.
4. Connect with the MCP Inspector: `npx @modelcontextprotocol/inspector` and use the unix socket (or a small rmcp client). `tools/list` shows `ui.state`, `ui.open_workspace`, `ui.open_request`, `ui.capture_prototype` next to the engine tools.
5. Call `ui.state`: the result lists the Workspace path, the tabs, `panel: "workspace"`, window size and scale, the theme and a `generation`.
6. Call `ui.open_request` with `{"key":"payments/get-payment.flux.md","permanent":true}`. The tab opens in the app; call `ui.state` again: the tab is listed, `active_tab` is its key and `generation` is higher. Calling `ui.state` twice without touching the app returns the same `generation`.
7. Open the Problems panel in the app, call `ui.state`: `bottom_tab` is `problems`.
8. Call `ui.open_request` with a missing key: a tool error with the notice text, and no tab opens.
9. Call `ui.capture_prototype` with `{"path":"/tmp/fw.png"}`. With Screen Recording granted to your terminal, `/tmp/fw.png` shows the window. Without it the call fails with a message naming the Screen Recording permission.
10. Quit the app: the socket file is gone. With `kill -9` a stale file is replaced on the next start.
11. Stdio: `target/debug/fluxwire --mcp-stdio fixtures/payments-api` serves the protocol on stdout (logs go to stderr).
12. A release build (`cargo build -p fluxwire --release`) has no `--mcp-*` flags: `strings target/release/fluxwire | grep -c ui.state` prints 0.

## Claude Code

```json
{"mcpServers":{"fluxwire-app":{"command":"fluxwire","args":["--mcp-stdio","."]}}}
```

Build `fluxwire` with `--features dev-mcp` and run `/mcp`; the server shows as connected with the `ui.*` tools.
