# M3 demo: sending HTTP requests

Start a local test target (any HTTP server works). For example, in another terminal:

```bash
python3 -m http.server 8000 --directory fixtures
```

Then `make run`, **Open folder**, `fixtures/payments-api`.

1. **Fix the URL.** The fixture requests use `{{baseUrl}}`, which arrives with M4. Open *Create payment* and press Send: the response pane says **Cannot send** and names `{{baseUrl}}`, `{{idemKey}}`, `{{customerId}}`. Create a new request (Cmd/Ctrl+N), then set the URL to `http://127.0.0.1:8000/payments-api/fluxwire.toml` (Cmd/Ctrl+L, type).
2. **Send.** Cmd/Ctrl+Enter. The status line shows status (coloured by class), total time, decoded size (and wire size when compressed), and the protocol (`HTTP/1.1` or `HTTP/2`). The request was never saved: the tab stays dirty and the file on disk is unchanged.
3. **Timeline.** Open the *Timeline* tab: queued, dns, connect, tls, sent, waiting, download and total as a waterfall. Send again: dns, connect and tls read **reused**. Against an `https://` URL (for example `https://httpbin.org/get` or `https://api.github.com`) tls and h2 show up.
4. **Body.** *Pretty* / *Raw* / *Hex* (and *Preview* for images). Use the JSONPath box (`$.items[*].id`, Enter), Find (Cmd/Ctrl+F, Enter jumps to the next match), *Wrap*, *Copy* and *Save*. Click the chevrons next to `{` / `[` to fold.
5. **Headers and cookies.** The *Headers* tab lists every response header; *Cookies* lists `Set-Cookie` values read-only.
6. **Cancel.** Point the URL at a server that stalls (`nc -l 9000` and `http://127.0.0.1:9000/`), press Send, then Esc or the **Cancel** button. The pane says **Cancelled**.
7. **Errors name the phase.** `http://127.0.0.1:1/` gives *Failed in the connect phase* with a fix; `http://no-such-host.invalid/` the dns phase; an https URL with a self-signed certificate the tls phase, suggesting to add the CA in `fluxwire.local.toml` or set `settings: verify_tls: false`.
8. **Copy as cURL.** Cmd/Ctrl+Shift+C copies the command with secrets masked (`Bearer ***`); the palette entry *request: copy as cURL (with secrets)* copies it unmasked.
9. **Paste cURL.** Copy `curl -X POST https://example.test/v1/x -H 'X-A: 1' -d '{"a":1}'`, focus the URL bar (Cmd/Ctrl+L) and paste: method, URL, header and body are filled in; prose in the file is untouched.
10. **Auth.** Add `auth:` front matter in text mode (`type: bearer`, `token: ...`; or `basic`, `apikey`, `digest`) and send to a server that echoes headers.
11. **Large responses.** Serve a 50 MB JSON file (`python3 -c "import json;print(json.dumps([{'id':i,'name':'item %d'%i} for i in range(900000)]))" > /tmp/big.json`) and request it. Bodies over 16 MiB are streamed to a temp file; the viewer pretty-prints on a background thread and scrolling stays virtualized.
12. **Console.** Cmd/Ctrl+J shows one line per send (and per redirect hop).

## TLS and proxy settings

Put these in `fluxwire.local.toml` next to `fluxwire.toml`:

```toml
[tls]
ca = ["certs/ca.pem"]

[[tls.client_cert]]
host = "api.internal"
cert = "certs/client.pem"
key = "certs/client.key"

[proxy]
url = "http://proxy.local:3128"
no_proxy = "localhost,.internal"
```

`HTTP_PROXY`, `HTTPS_PROXY` and `NO_PROXY` are honoured when `[proxy]` is absent. Per-request `settings:` front matter accepts `timeout_ms`, `follow_redirects`, `max_redirects` and `verify_tls`.
