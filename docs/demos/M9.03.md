# M9.03 demo: History viewer

1. **Open the tab.** Open `fixtures/payments-api` and send a few requests (change the URL or send from different requests, and send one against a closed port so it fails). Press Cmd/Ctrl+Shift+H (or click the History icon in the status bar): a single **History** tab opens. Opening it again focuses the same tab.
2. **Table.** Rows sit under day headers. Click a column header to sort (arrow shows direction); drag a header's right edge to resize. Restart the app: widths and sort are remembered.
3. **Detail pane.** Click a row: the right pane shows the request and response without opening a tab. Select the failed send: it shows the error and phase, not a blank body. Drag the divider to resize the pane.
4. **Filters.** Type in the search box (name or URL); toggle method, status-class, 24 h / 7 d, *unsaved* and *pinned* chips; each active filter appears as a removable chip. Esc (or *Clear filters*) clears them. The stats strip shows count, success rate, p50 and p95 for the filtered set.
5. **Pin and note.** Select a row, press `p` (pin glyph appears) and `n` to type a note (saved on blur; a note glyph appears). Use Clear ▾ → All history: the confirm offers *Clear* (pinned stay) and *Clear including pinned*.
6. **Diff.** Press `d` on two rows (or tick them) to open a diff tab. In the detail pane, *Compare to previous* diffs against the last send of the same request. *Restore* (or Enter) puts the request into an unsaved tab.
7. **Navigator.** Click the History panel in the left dock: it lists Timeline, Saved views and Requests with counts, and no entries. Click *Failures*: the tab filters to failed sends and the item is highlighted. Right-click a request: *Show history*, *Clear history for this request*.
8. **Folder runs.** Run a folder, then open *Folder runs*: the sends collapse into one expandable row with passed/failed counts.
9. **Export.** Export ▾ → JSON or CSV writes the whole filtered set (not just the loaded page).
10. **Quick search.** `⌘K`, then `!`: choosing a result opens its history entry.

**Deferred:** a custom time-range picker; sticky day headers; re-send from an entry; the real response viewer (search, filter, collapse) inside the detail pane (it shows highlighted read-only blocks); `fw.ws.*` frames search; user-defined saved views; `!` search over the whole store (it indexes the loaded page).
