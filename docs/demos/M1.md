# M1 demo: UI shell

Run `make run` (macOS without Xcode's Metal toolchain is handled automatically). Everything below uses mock data; nothing touches the network or disk. `Cmd` means `Ctrl` on Linux and Windows.

1. **Window.** The shell opens on the `payments-api` workspace: title bar (workspace, `main`, environment pill `staging`, search box), left dock, tab bar, request editor over the response pane, status bar.
2. **Workspace panel.** Click folders to collapse and expand. Single-click a request: an italic preview tab opens and the next single-click replaces it. Double-click: the tab becomes permanent.
3. **Tabs.** Method text is coloured per method; the WebSocket request (`events/order-stream`) shows `⇄`. Right-click a tab to pin or unpin it (pinned tabs sort first). Click `×` to close; `Cmd+Shift+T` reopens. Type in the URL bar: the dirty dot appears; `Cmd+S` clears it. `Ctrl+Tab` cycles.
4. **Request editor.** Click the method to cycle it. Sub-tabs Params, Headers, Body (highlighted JSON), Auth, Scripts (Pre/Post toggle), Tests, Docs, Settings, with counts. Disabled params show dimmed with an empty checkbox.
5. **Response pane.** Status line, then Body, Headers, Cookies, Timeline (waterfall), Tests, Console. `Cmd+Alt+L` flips the split between stacked and side by side.
6. **Left dock.** Status-bar icons switch Workspace, History, Environments (click to select, double-click to open an Environment tab), Sync. Drag the dock edge to resize.
7. **Page tabs.** Double-click an environment (⚙), click a History row (⟲, read-only), click the Sync row (⇅), `Cmd+Shift+R` (▶ folder run), palette "docs: open for request" (¶).
8. **WebSocket tab.** Messages sub-tab with composer and message log; the Connect button toggles to Disconnect.
9. **Bottom dock.** `Cmd+J` toggles Console and Problems; the status-bar warning count opens Problems.
10. **Command palette** (`Cmd+Shift+P`): lists every registered action with its binding. Type to filter, `↑/↓` to move, `Enter` to run, `Esc` to close.
11. **Quick search** (`Cmd+K`): requests and environments. `Enter` opens.
12. **Environment picker** (title-bar pill or `Cmd+E`).
13. **Theme.** Palette → "theme: toggle" recolours the whole UI between One Dark and One Light. The app also follows the OS appearance.
14. **Welcome view.** Palette → "workspace: close (show welcome)" shows Open folder / New collection / Import and recent workspaces; "Open folder" returns.
