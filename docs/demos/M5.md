# M5 demo: History

1. `make run`, open `fixtures/payments-api`, open **Create payment** and point its URL at a server you can reach.
2. Send it five times (Cmd/Ctrl+Enter), changing the URL, a header or the body between sends. Open the **History** panel (status-bar clock icon): entries are grouped by day, newest first.
3. Filter: click `POST` / `2xx` chips, or type part of a name or URL in the filter box.
4. Click an entry: a read-only, italic ⟲ tab shows the stored request and response. Double-click to keep it open.
5. Quit and relaunch: the five entries are still there.
6. Click `⇄` on the first entry, then `⇄` on the fifth: a diff tab shows request and response headers and a JSON-aware body diff side by side.
7. In an entry tab: **Restore** puts the request into an unsaved tab of its file; **Copy as cURL** copies a redacted command.
8. In the response pane, **History ▾** lists recent sends of this request; pick one to see that response, **Back to latest** to return.
9. Secrets: send with a bearer token, then confirm the database has none of it:
   `grep -c "<token>" "$FLUXWIRE_DATA_DIR/history.sqlite"*` prints `0` for each file (default data dir on macOS: `~/Library/Application Support/fluxwire`).
10. Retention: put `[history]\nmax_entries = 3` in `settings.toml`, relaunch; only the three newest remain. **Clear request / collection / all** (panel footer or palette) removes entries.
