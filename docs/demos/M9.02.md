# M9.02 demo: environment management and text input

1. **Switcher.** Open `fixtures/payments-api`. Click the environment pill (or Cmd/Ctrl+E): the rows are *New environment…*, `devel` (✓ active), `local`, `staging`, `test`, *No environment*, *Manage environments…*. Each shows its `baseUrl` host or variable count.
2. **Create from the query.** Type `qa`: the first row is *Create environment “qa”*. Enter creates `environments/qa.env`, activates it, and opens its editor with the caret in the first Name cell. The tab is not dirty.
3. **Edit without saving.** Type `baseUrl`, Tab, `http://localhost:4000`. The tab shows a dirty dot and `qa.env` is unchanged on disk. Hover `{{baseUrl}}` in a request, or send it: both use `localhost:4000`.
4. **Secrets.** Add `token`, tick its Secret checkbox (the value is masked; the eye button in the box reveals it for 10 s), press Cmd/Ctrl+S. `qa.local.env` holds `token`, `qa.env` does not, and the value is masked; Copy is refused until you *Reveal secrets*.
5. **Validation.** Name a row `1bad`: the row shows `E101` and Problems lists it. Save skips it and says how many rows were skipped.
6. **Undo and close.** Use Undo/Redo in the toolbar. Edit and press the tab's ×: *Save / Discard / Cancel*.
7. **External change.** Edit `qa.env` by hand: a clean tab reloads silently; a dirty tab shows *Reload* / *Keep mine*.
8. **Panel.** Open the Environments panel: click a row (preview tab, not activated), double-click (pinned), click the dot (activates), use the row buttons to rename, duplicate, delete (the confirm lists the files).
9. **Workspace-level.** In a workspace with two collections the panel, pill, and switcher are unchanged: one list of environments from `<workspace>/environments/`, one active environment used by requests in both collections.
10. **Text fields.** In the URL bar, a header value, the palette, an environment value: drag-select, Shift+arrows, word jumps, Cmd/Ctrl+A/C/X/V/Z, right-click menu. Type `é` with a dead key.
