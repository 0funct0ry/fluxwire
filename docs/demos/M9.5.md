# M9.5 demo: semantic UI tree

Build and start the app with the in-app host:

```bash
cargo run -p fluxwire --features dev-mcp,runtime-shaders -- --mcp-socket /tmp/fluxwire.sock fixtures/payments-api
```

From an MCP client on the socket:

1. `ui.tree` with `{"role": "button"}` lists the buttons with ids, labels, bounds, `visible`,
   `clipped`, `focused` and `z`.
2. `ui.find` with `{"label": "Send"}` returns `toolbar.send` and its bounds.
3. `ui.click_element` with `{"id": "toolbar.send"}` sends the request; `ui.wait_for_idle`, then
   `ui.state` shows the response.
4. `ui.click_element` with `{"id": "title.env-pill"}` opens the environment switcher; the tree now
   has the pill covered, and clicking it again errors.
5. Two `ui.tree` calls on an unchanged state return identical JSON.
