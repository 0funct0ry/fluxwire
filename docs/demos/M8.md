# M8 demo: WebSockets

`make run`, open `fixtures/payments-api`. You need a WebSocket server. Any echo server works; for example
`npx wscat --listen 9001` in a terminal (or `websocat -s 9001`).

1. **New request.** Palette → `workspace: new WebSocket request`, or open `events/order-stream`. Set the URL
   line to `ws://127.0.0.1:9001/` (Open as text, or edit the URL bar).
2. **Connect.** Click Connect (palette `websocket: connect or disconnect`). The button reads Cancel while
   connecting and Disconnect once open; the status line shows `● Connected`. Console shows the send.
3. **Saved messages.** Messages tab lists every `<lang> message <label>` block. Select one and press
   Cmd/Ctrl+Enter, or click its Send. The log shows `↑` (sent) and `↓` (echo) frames with offsets and sizes.
4. **Composer.** Write `{"op":"ping"}` in the composer, press Send (or Cmd/Ctrl+Enter while it has focus).
   *Save as message* inserts a `json message message-N` block with a span insert; `git diff` shows only that block.
   `{{variables}}` in messages are interpolated at send time.
5. **Log.** Click a frame to expand it below the list (JSON is pretty-printed, binary is a hex dump). Filter by
   direction (All / Sent / Received) and by text. Clear empties the log.
6. **Headers and auth.** Headers tab edits the upgrade request; front matter `auth` (basic, bearer, apikey) applies.
   `wss://` uses the TLS settings from `fluxwire.local.toml`; `settings: verify_tls: false` skips verification.
7. **Disconnect.** Click Disconnect: a close frame is sent and the status shows `○ Disconnected (code 1000)`.
   A server that is down shows the failed phase (`connect`) with a fix; a 401 shows `upgrade`.
8. **History.** The History panel lists the session (`WS 101 · N frames`). Open it: handshake headers and the
   transcript (first 1,000 frames) in the same session-log component. Restore reopens the request.
9. **Tests.** `cargo test -p fluxwire-ws` runs the axum echo/broadcast tests and the conformance suite;
   `cargo test -p fluxwire-runner` covers a session run through the runner.
