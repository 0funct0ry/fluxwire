# M9.05 demo

1. Run `make run`, press Cmd/Ctrl+Shift+P, type `theme: select…`, press Enter. The list shows `Follow system appearance` and 53 themes; the current one is checked and highlighted.
2. Press Down/Up, PageDown, End: the whole window repaints in the highlighted theme. Type `solarized`: the first match previews. Type `zzzz`: the original theme returns. Press Esc: the original theme is restored exactly.
3. Reopen, pick `Dracula`, press Enter. The status bar shows `Theme: Dracula` and `settings.toml` (user config dir) contains `theme = "Dracula"`, with every other line unchanged.
4. Quit and relaunch: the app opens in Dracula. Change the OS appearance: nothing changes.
5. Open the palette, type `~nord`: `Theme: Nord` and `Theme: Nordfox`. Arrow between them to preview; Esc restores; Enter keeps and writes the setting. `>nord` and unprefixed quick search (Cmd/Ctrl+K) show no themes.
6. Run `theme: select…` → `Follow system appearance`: the `theme` key disappears and the app follows the OS again.
7. Edit `settings.toml` to `theme = "Nope"` and relaunch: One Dark/One Light with `Unknown theme "Nope" in settings.toml; using …`. Break the file (`not toml ===`), choose a theme: it applies, the notice says it was not saved, and the file is untouched.
8. `theme: toggle` still flips One Dark ↔ One Light and does not touch `settings.toml`.
9. With Solarized Light, Gruvbox Light Hard, Catppuccin Latte, Dracula, Tokyo Night and Poimandres, look over the title bar, docks, tree, tabs, request editor highlighting, response viewer, history tab, palette, dialogs and status bar.
