# M2 demo: collections on disk

Run `make run`, or open the sample directly: `make run` then **Open folder**, or `cargo run -p fluxwire -- fixtures/payments-api`.

1. **Open folder.** On the welcome view click *Open folder* and choose `fixtures/payments-api`. The Workspace panel shows Auth, Payments, refunds, events and README.md, read from disk. The status bar shows the real git branch and `⚠ 0`.
2. **Open a request.** Click *Create payment* (preview tab, italic), double-click to keep it. Params shows `expand` and a disabled `debug`; Headers shows three rows plus the disabled `X-Debug`.
3. **Edit from the form.** Press Cmd/Ctrl+L and type in the URL, click a header value and edit it, tick/untick a row, use *Add header*. The tab gets a dirty dot; nothing is written yet.
4. **Save.** Cmd/Ctrl+S. In a terminal run `git diff fixtures/payments-api`: only the lines you changed differ, prose is untouched.
5. **Open as text.** Click *Open as text* (or palette: `request: open as text`). Edit the file directly (typing, arrows, Enter keeps indent, Cmd/Ctrl+Z undo, paste). *Form view* shows the same document.
6. **Scripts and tests.** Scripts shows the `ts pre` block; Post and Tests offer *Add block*, which inserts the block at its default position.
7. **Create things.** Cmd/Ctrl+N creates a request in the selected folder (prompts for a name); right-click a folder for New request / WebSocket request / folder, Rename, Duplicate, Delete (to the OS trash), Reveal in file manager. Drag a request onto another folder to move it.
8. **New collection.** On the welcome view (palette: `workspace: close`) choose *New collection* and pick an empty directory: `fluxwire.toml` (`format = 1`), `collection.flux.md`, `.gitignore`, `environments/` are created.
9. **Unsupported content.** Open `fixtures/format-edge` and the request *Future gRPC*: a banner says it needs `grpc`, *Other content* lists `x-owner`, `retry`, the `json schema` and `x-acme-lint` blocks, and Send is disabled. Save, then check the file is byte-identical.
10. **Malformed file.** Open `malformed.flux.md` from the same folder; the Problems panel (Cmd/Ctrl+J, Problems) lists F101, F104, F201, F301, F403... Click one: the file opens as text with the caret at the span.
11. **External edit.** With a request open and saved, change it in another editor: the tab updates within ~200 ms. Make an unsaved edit, then change the file externally: the conflict bar offers *Reload* / *Keep mine*.
12. **Restart.** Make an unsaved edit, quit (Cmd/Ctrl+Q) and relaunch: the workspace, tabs and the unsaved text return.
13. **Format version.** Set `format = 2` in a copy of `fluxwire.toml` and open it: the app refuses with a clear message.
