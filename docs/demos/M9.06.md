# M9.06 demo

1. Run `make run`, open `payments/create-payment.flux.md`, and choose the **Body** sub-tab. Type `{` then Enter: the braces gain an indented empty line. Type `"`, then a letter, then `"`: the second quote steps over the closer. Type `[` and press Backspace: both characters disappear.
2. Select several lines and press Tab, then Shift+Tab: they indent and outdent together. Press `Cmd/Ctrl+/`: nothing happens in JSON. Press `Alt+Up` and `Alt+Down` to move a line; `Cmd/Ctrl+Shift+D` duplicates it.
3. Put `{"amount":{{amount}},"tags":[1,2]}` in the body and run **request: format body** (palette or `Alt+Shift+F`): it pretty-prints, `{{amount}}` is untouched, and one `Cmd/Ctrl+Z` restores the compact text. Break the JSON and run it again: nothing changes and the status bar says `Body is not valid JSON (line L, column C)`.
4. In the Body, type `{{`: the active environment's variables appear with their source. Enter inserts `name}}`. Esc closes the menu without cancelling a send.
5. Open **Scripts**. Type `fw.`: the API appears with signatures and documentation. Type `fw.response.headers.` then `fw.expect(1).not.`, then `fw.vars.get("`: members, matchers and variable names. Type `test` and press Tab: the snippet appears with `name` selected. `Cmd/Ctrl+/` toggles `//`.
6. Use an input method (Japanese, or macOS press-and-hold on `e`) in the Body and Scripts editors: composition is underlined and commits once.
7. **Open as text**: on a new front matter line the keys appear with descriptions (`tags`, `seq`, …); after ```` ``` ```` the fence languages and roles appear, reserved ones marked; inside a `ts pre` fence the script completions appear.
8. **Docs**: the tab opens in **Preview** (rendered Markdown, read-only; links open in the browser; a block label such as `ts pre · edit in Scripts` opens that sub-tab). Press **Source** to edit: type prose after the front matter; Enter continues a list and ends it on an empty item; select a word and type `*`. Typing inside a code block does nothing. Check the file on disk: only the prose changed.
9. Press `Alt+Z` in a long line to soft-wrap it; click and drag across wrapped rows. Press `Ctrl+G`, enter `3:2`: the caret moves.
10. Add `[editor]` keys to `settings.toml` (`tab_size = 4`, `soft_wrap = "editor_width"`, a `[editor.languages.json]` override): open editors change when the file is saved.
11. WebSocket tab: compose a message in the composer (it now has IME and editing keys). Environment editor: Bulk edit shows `.env` and `.local.env` in editors.
12. Try One Dark, One Light and two microterm themes: the editors follow the theme.

12b. With `[editor] show_whitespace = "all"` spaces and tabs show as `·` and `→`; indent guides follow the tab size; put the caret beside a bracket to see both brackets boxed. In the Body, `{{name}}` shows in the accent colour and an undefined `{{nope}}` is red and underlined. In Docs, code blocks are muted with a bar in the gutter and a chip such as `http request · edit in Params/Body`; clicking it opens that sub-tab.
