# M9.2 demo

1. `make build`, then start a server that may write and execute:
   `target/debug/fluxwire mcp serve --allow read,write,execute --root fixtures/payments-api`
   (or `npx @modelcontextprotocol/inspector target/debug/fluxwire mcp serve --allow read,write,execute --root fixtures/payments-api`).
2. `list_requests` with `path` = the fixture's absolute path lists its requests. `diagnostics` and `read_request` on `payments/get-payment.flux.md` return the source, blocks, and diagnostics with byte spans.
3. `list_environments` shows `devel`, `local`, `staging` and `test` with variable names; `clientSecret` and `apiKey` are flagged `secret` and no value appears. `resolve_vars` with `text` `{{baseUrl}} {{clientSecret}}` and `env` `local` masks the secret.
4. `fmt` with `dry_run: true` on a file returns a diff and changes nothing; without it the file is rewritten to the canonical bytes, and a second call reports `changed: false`.
5. `write_request` with `edits` (byte offsets from `read_request`) changes only those spans and returns the diff. A path outside `--root` is refused.
6. Start the sample API from `fixtures/payments-api` (or point `baseUrl` at any server), then `send_request` with `env` and `run_folder` on `payments` return redacted results. Open the app's History tab: rows from these calls carry an `agent` tag, and `history_query` with `origin: "agent"` lists them.
7. A Collection with scripts that is not trusted (`scripts: trust collection` in the app) is not sent: the result says `not run: the Collection is not trusted`. Trust it in the app and call again; scripts run.
8. While a long `run_folder` runs with `cancel_key: "k"`, `cancel` with `key: "k"` stops it.
9. With `--allow read`, only the read tools are listed; calling `send_request` is refused.
