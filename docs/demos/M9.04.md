# M9.04 demo

1. Open a workspace with a collection and press Cmd/Ctrl+Shift+P: only curated entries show (no `input:`, `modal: dismiss`, `tab: next`…). Press the keys again: the palette closes.
2. Type `sidebar`, `console`, `keymap: show`, `settings: show`, `scripts: trust collection`: the new labels.
3. `environment: delete…` is absent with no environment selected and present once one is active.
4. `workspace: new collection` and `collection: new…` both open the New collection dialog; `workspace: copy path` puts the root on the clipboard.
5. Cmd/Ctrl+S, Cmd/Ctrl+Enter, Esc and Ctrl+Tab still work.
6. Run `keymap: edit`: Edit a row, press keys (Esc cancels); Clear; Reset. Rebinding onto a used key shows a conflict with Replace/Cancel. `keymap.toml` keeps your comments and takes effect without restart.
