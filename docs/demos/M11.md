# M11 demo: imports

```bash
cargo build -p fluxwire-cli
alias fw=target/debug/fluxwire-cli
```

1. **Postman with tests.** `fw import postman fixtures/import/postman/shop-tests.postman_collection.json --into /tmp/shop --report /tmp/shop-report.md`. The command prints the lossy items (`pm.visualizer`, `require('moment')`, an `awsv4` auth). `fw validate /tmp/shop` exits 0. Open `/tmp/shop/list-products.flux.md` to see the `js test` block that runs through the `pm` shim.
2. **Run the folder.** Point `baseUrl` at a local server and `fw run /tmp/shop`; tests execute through the shim (the automated version is `crates/fluxwire-import/tests/postman_run.rs`).
3. **Secrets.** `fw import postman fixtures/import/postman/local.postman_environment.json --into /tmp/shop`. `environments/local.local.env` holds `password` and `apiToken`, `fluxwire.toml` lists them under `[secrets]`, and `.gitignore` has `*.local.env`.
4. **OpenAPI with a Spec link.** `fw import openapi fixtures/import/openapi/petstore.yaml --into /tmp/pets --spec-link`. Tags become folders, `[[openapi]]` is written, and `.fluxwire/sync/petstore.base.json` holds the base snapshot.
5. **Other sources.** `fw import hurl fixtures/import/hurl/login-flow.hurl --into /tmp/hurl` (a sequential folder, captures, a `ts test`), `fw import http fixtures/import/http/users.http --into /tmp/http` (environments from `http-client.env.json`), `fw import insomnia fixtures/import/insomnia/bookstore.insomnia.json --into /tmp/ins`. `fw import auto <file> --into DIR` detects the source.
6. **No overwrites.** Repeat step 1: existing files are listed as `skipped (exists)`. Add `--overwrite` to replace them. `--dry-run` writes nothing.
7. **Wizard.** `make run`, open `fixtures/payments-api`, run `workspace: import` from the palette, or drag `fixtures/import/postman/orders.postman_collection.json` onto the window. Check the detected source, change the target, read the preview tree and report, tick an existing file to overwrite it, and click Import. The first request opens.
8. **Errors.** `fw import postman bad.json --into /tmp/x` exits 65; `fw import nonsense f --into /tmp/x` exits 64.
