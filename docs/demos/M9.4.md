# M9.4 demo

1. Build with the MCP host: `cargo run -p fluxwire --features dev-mcp,runtime-shaders -- --mcp-socket /tmp/fw.sock fixtures/payments-api` (macOS without Metal needs `runtime-shaders`).
2. Connect an MCP client to the socket (for example the MCP inspector) and call `ui.list_actions`. `fluxwire::Send` shows `enabled: false` with no request open.
3. `ui.invoke_action` with `{"name": "Send"}` returns an error naming the disabled action.
4. `ui.command` with `{"command": "open_file", "key": "payments/get-payment.flux.md", "permanent": true}`, then `ui.command` `{"command": "choose_environment", "name": "local"}`.
5. Start the sample API for `baseUrl`, then `ui.invoke_action` `{"name": "Send"}` (or `ui.key` `{"keys": "secondary-enter"}`).
6. `ui.wait_for` `{"path": "/response/status"}` returns once a status exists; read status, size and timings from the result, and the body via the response tools.
7. `ui.command` `set_url` edits the target; the tab turns dirty in `ui.state`. `ui.type_text` types into the focused input.
8. `ui.click` and `ui.scroll` report that pointer input is unsupported on gpui 0.2.2 (deferred to M9.5).
