# M9.7 demo: UI audit

Start the app with the in-app host:

```bash
cargo run -p fluxwire --features dev-mcp,runtime-shaders -- --mcp-socket /tmp/fluxwire.sock fixtures/payments-api
```

From an MCP client on the socket:

1. `ui.audit` with `{}` lints the current view: each finding has `rule`, `severity`, `message`,
   `ids`, `bounds` and `fix`. `by_rule` summarizes counts.
2. `ui.audit` with `{"rules": ["UX103"]}` lists controls smaller than 20 points (the 12 to 16 point
   table checkboxes and tab-bar icons).
3. `ui.audit` with `{"states": ["env-modal", "palette-open"], "themes": ["one-dark", "one-light"],
   "sizes": ["default", "min"]}` sweeps the matrix; every cell is labelled `state/theme/size`
   and the theme and window size are restored afterwards.
4. `ui.audit` with `{"rules": ["UX110"], "themes": ["one-light"]}` reports One Light's `created` and
   `modified` colours below 3:1 on the surface.
5. `ui.walkthrough` with
   `{"steps": [{"step": "key", "keys": "cmd-shift-p"}, {"step": "type", "text": "send"},
   {"step": "key", "keys": "enter"}, {"step": "wait_idle"}]}` reports per-step `ms`, `keystrokes`,
   `clicks` and `notice`, and totals; run it again later to compare the cost of the same task.
6. Two `ui.audit` calls on an unchanged state return identical findings (UX150 aside, which
   reports measured timings).

## Deferred

Triage of the current UI (the cheap fixes were not code changes; these need layout work):

- **UX103:** table checkboxes (`params`, 12x12; `center.editable_table`, 16x12), tab-bar controls
  (16x16) and the dock row dots (20x20 is at the minimum, so only the 12 to 16 point ones are flagged).
- **UX101:** `toolbar.url`, `toolbar.text-mode` and `status.sync` are reported clipped with no tooltip.
- **UX110:** One Light `created` and `modified` fall below 3:1 on the surface; the bundled theme
  was not changed.
- **UX130:** informational list of hidden actions with no binding (`ShowResponse*`, `NewFolder`, ...).
- **UX131 and UX150:** most controls do not yet declare `focusable` or `focus_visible` through
  `dev_tag_meta`, so keyboard reachability is only checked where a focus handle is tagged. Frame
  time over 16.7 ms is seen in debug builds.
- **UX140:** fixtures for response loading, history empty and environments empty do not exist yet.
- Pointer-level audit (hover and focus visuals) needs pointer injection, unavailable in gpui 0.2.2.
