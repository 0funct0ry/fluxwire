# M9.6 demo

Needs a visible window. On macOS, grant Screen Recording to the app that starts fluxwire (Terminal, iTerm or your editor); on Linux install `grim` or ImageMagick (`import`), under xvfb for headless runs.

1. Build and start with the MCP host: `cargo run -p fluxwire --features dev-mcp,runtime-shaders -- --mcp-socket /tmp/fw.sock fixtures/payments-api`.
2. Start the sample API and echo server for the `local` environment (used by `response-200-json`, `folder-run-failed` and `ws-session-open`).
3. Connect an MCP client to the socket. Call `ui.screenshot` with `{"state": "env-modal"}`. The result has the PNG, `tier`, `scale`, `size` and the `ui.state` JSON (`modal` is set).
4. Call `ui.screenshot` with `{"state": "folder-run-failed"}`, then `{"state": "ws-session-open"}`. Each opens its Workspace if needed, runs its steps, waits for idle and captures.
5. Call it again with `{"state": "env-modal"}`: the two images are identical after masking (response time and timeline are filled grey).
6. Call `ui.set_theme` with `{"name": "one-light"}` and `ui.screenshot`; then `ui.resize` with `{"size": "compact"}` and capture again. Settings are not written.
7. Crop to an element: `ui.find` `{"label": "Problems"}` for an id, then `ui.screenshot` with `{"element": "<id>"}`.
8. Call `ui.screenshot_all` with `{"states": ["response-200-json", "palette-open"], "themes": ["one-dark", "one-light"], "sizes": ["default", "compact"]}`: eight labelled images (`state/theme/size`); theme and window size are restored.
9. Revoke Screen Recording (macOS) and call `ui.screenshot` again: the error names the permission to grant; no blank image is returned.
10. Explicit steps instead of a name: `{"state": [{"step": "invoke", "name": "CommandPalette"}, {"step": "wait_idle"}]}`. Mask nothing with `{"mask": []}`.
