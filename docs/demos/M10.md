# M10 demo: headless CLI

```bash
cargo build -p fluxwire-cli
alias fw=target/debug/fluxwire-cli
```

1. **Run.** `fw run fixtures/cli-smoke --env ci` (start `python3 -m http.server 8099` with a `health` file first) prints a tree; `echo $?` is `0`. Stop the server: exit `2`.
2. **Reporters.** `fw run fixtures/cli-smoke --env ci -r tap -r junit -o out.xml` prints TAP and writes JUnit; `-r json | jq .summary`.
3. **Send.** `fw send fixtures/cli-smoke/health.flux.md --env ci -i`: body on stdout, timing on stderr.
4. **Format.** Break a file's trailing newline: `fw fmt --check fixtures/...` exits 1 and lists it; `fw fmt` fixes it.
5. **Validate.** `fw validate fixtures/payments-api` prints diagnostics (65 on errors, 66 for F401).
6. **Misc.** `fw env list fixtures/payments-api`, `fw completions zsh`, `fw import x` (stub, exit 64), `fw --version`.
7. **Static.** `make cli-static`, then run the binary in `alpine` (CI job `cli-static` does this).
8. **App.** `make run`, palette → `cli: install shell command`; `fluxwire --version` works in a new shell.
