# M9.07 demo

1. Run `make run`, open `fixtures/payments-api`, right-click the `payments` folder: the menu shows **New request…**, **Quick request**, **New folder**, **Run folder**.
2. **New request…**: `Save in` shows `payments`. Choose HTTP, type the name `List users`, method POST, URL `{{baseUrl}}/users`. The line under the name reads `Creates payments/list-users.flux.md`. Press Enter: the request opens in a pinned tab with the URL focused and the status bar says `Created payments/list-users.flux.md`. Run `fluxwire fmt` on it: no change.
3. Open the dialog again, choose **From cURL**, paste `curl -X POST https://x.test/v1/p -H 'Content-Type: application/json' -d '{"a":1}'`. The summary shows `POST https://x.test/v1/p · 1 header · JSON body 7 B`; the name is left empty and the file becomes `post-p.flux.md`. Secondary-Enter creates it.
4. Paste `curl --weird x` instead: Create is disabled and the footer says why. Add `-o out` to a valid command: a warning lists the ignored flag.
5. Choose WebSocket and enter `https://x.test/`: the URL error appears and Create is disabled.
6. Open the dialog with a `curl …` command on the clipboard: the hint **Paste cURL command from clipboard** switches to From cURL and fills the field.
7. Press Esc: nothing is created. With text in the cURL field the first Esc warns, the second closes.
8. Use the palette entry **workspace: quick request**: the inline name row still creates a GET request.
9. Open **Save in**, filter by folder name and pick another folder; the preview path follows.
