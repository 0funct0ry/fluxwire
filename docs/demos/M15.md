# M15 demo: marketing page and docs site

1. **Build.** `make site` (runs `npm ci && npm run build` in `site/`). `make site-check` additionally checks internal
   links and AA contrast in both themes.
2. **Preview.** `cd site && npx astro preview`, then open `http://localhost:4321/fluxwire/`. The hero shows a `.flux.md`
   file beside the response waterfall; scroll through the review, feature, comparison (including the rows Fluxwire
   loses: GraphQL, gRPC, team workspaces, mock servers) and install sections. The theme button toggles light and dark;
   the install tabs and Copy buttons work from the keyboard.
3. **Docs.** Open `/fluxwire/docs/`. Walk Getting started, Guides, Reference and Project in the sidebar. Press `/` to
   search; results come from Pagefind.
4. **Generated pages.** In Reference, open *The fw script API*, *Command-line reference*, *Front matter reference*,
   *Roles and info strings*, *Keybindings* and *Exit codes*. Change a flag in `crates/fluxwire-cli`, run
   `npm run gen` in `site/`, and watch the CLI page change.
5. **Schema.** `/fluxwire/schema/front-matter.schema.json` serves the published JSON Schema.
6. **install.sh.** `make install-script` stages `site/public/install.sh`, served at `/fluxwire/install.sh`.
7. **In the app.** `make run`, open the palette and type `help:`: *open documentation*, *open format reference*,
   *open keybindings reference* and *report an issue* open the deployed site and the GitHub tracker.
8. **Screenshots.** `make screenshots` captures PNGs from the dev-mcp scenarios into `site/public/screenshots/`.
9. **Deploy.** Pushing a change under `site/` to `main` runs `.github/workflows/pages.yml`. Tag `v1.0.0` after this
   milestone.

Tests: `cargo test -p fluxwire-cli --test reference`, `cargo test -p fluxwire-ui help_links`.
