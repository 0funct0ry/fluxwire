# M6 demo: tabs, quick search, command palette

`make run`, open `fixtures/payments-api`.

1. **Quick search.** Cmd/Ctrl+K, type `create refund`: matches are highlighted in the results. Try a URL fragment (`v1/payments`). Prefixes: `@stag` environments, `/refunds` folders, `#billing` tags (front matter `tags:`), `!` recent history, `>` the command palette. Enter opens; Cmd/Ctrl+Enter opens the result next to the active tab. Recent workspaces show up too; Cmd/Ctrl+Enter opens one in a new window.
2. **Command palette.** Cmd/Ctrl+Shift+P lists every action with its binding; recently used ones come first. Run `tab: close others`, `request: show headers`, `response: show timeline`, `environment: new`, `view: toggle split orientation`.
3. **Tabs.** Right-click a tab for pin, close, close others, close to the right, close clean tabs, copy path. Hold Ctrl and press Tab repeatedly: a switcher lists tabs by recency; release Ctrl to commit (Esc cancels). `tab: group by kind` groups tabs with a divider. Cmd/Ctrl+Shift+T reopens the last closed tab (also after a restart).
4. **Layout.** Drag the left dock edge and the bottom dock's top edge, toggle Cmd/Ctrl+Alt+L, switch panels. Quit and relaunch: tabs (all kinds), the active tab, scroll positions, dock sizes, active panel, split orientation and tab grouping are restored per workspace.
5. **Keymap.** Palette → `settings: open keymap.toml`, add
   ```toml
   [[bindings]]
   "cmd-r" = "request::Send"
   ```
   and save: Cmd+R sends immediately, Cmd+Enter no longer does. A typo (unknown action or key) shows a K00x warning in Problems.
6. **Keybindings tab.** Palette → `keymap: open keybindings`, search by action, key or context.
7. **Welcome view.** Close the workspace (`workspace: close`): recent workspaces list name and path, with *New window* and × (forget).
