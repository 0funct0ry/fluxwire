# M13 demo: API documentation

```bash
make run
```

1. **Open the fixture.** Open `fixtures/payments-api` as a Workspace and open `Create payment`.
2. **Docs tab.** Select the Docs sub-tab. The Preview shows the heading, the prose, a chip for each executable block and the generated sections (Request, Parameters, Headers, Example body, Expected response) beneath.
3. **Modes.** Press Edit, Preview and Split. In Split, type a sentence into the first paragraph and watch the Preview update. Try typing inside the `http` fence: the editor refuses.
4. **Chips.** Click the `3 tests`/`pre script` chip; the Scripts or Tests sub-tab opens.
5. **Links.** Add `[see refunds](../refunds/create-refund.flux.md)` to the prose, switch to Preview and click it: `Create refund` opens. Add `[docs](https://example.com)`; it opens in the browser.
6. **Save as example.** Send the request, run `response: save as example` from the palette. An `http example` block appears at the end of the file (credentials and secrets redacted) and renders as a sample in the Preview. Run `git diff` on the file: only that block is added.
7. **Search.** Press the quick-search shortcut and type a heading of the request; the heading is listed.
8. **Export.**
   ```bash
   cargo run -p fluxwire-cli -- docs export fixtures/payments-api --out /tmp/payments-site
   open /tmp/payments-site/index.html
   ```
   Disable JavaScript in the browser: the page is unchanged. Switch the OS between light and dark appearance: the page follows. Validate the file with the W3C Nu checker or `tidy -e`.
9. **GitHub parity check (manual).** Push `fixtures/payments-api` to a scratch repository and open `payments/create-payment.flux.md` on GitHub. The prose, tables, task lists and code blocks render as in the Preview; the only differences are Fluxwire's chips and generated sections.
