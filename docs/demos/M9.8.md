# M9.8 demo

Needs a display (xvfb on Linux). On macOS grant Screen Recording to the app that starts fluxwire, or pass `--no-capture`.

1. Start the app with the MCP host: `cargo run -p fluxwire --features dev-mcp,runtime-shaders -- --mcp-socket /tmp/fw.sock fixtures/payments-api`.
2. Run a shipped scenario from a shell: `cargo run -p fluxwire --features dev-mcp,runtime-shaders -- mcp scenario fixtures/scenarios/m02-collections.yaml --socket /tmp/fw.sock --out target/shots`. It prints one line per step and `PASS m02-collections`; screenshots land in `target/shots`.
3. Run the whole set: `scripts/smoke-ui.sh fixtures/scenarios/m02-collections.yaml fixtures/scenarios/m04-environments.yaml fixtures/scenarios/m07-scripts-trust.yaml fixtures/scenarios/m08-websocket.yaml` (starts and stops the app itself).
4. Break one on purpose: run `fixtures/scenarios/broken-assertion.yaml`. It exits 1, prints `failure: expected /bottom_tab to equal "console", got "problems"`, and `--out` has the failure screenshot.
5. From Claude, call `ui.run_scenario` with `{"name": "m04-environments"}`: the report and the checkpoint image come back. With `{"scenario": {"name": "adhoc", "steps": [...]}}` an inline one runs.
6. Record: `ui.record` `{"action": "start"}`, then `ui.invoke_action` `{"name": "ShowProblems"}`, then `ui.record` `{"action": "stop", "name": "problems"}`. The YAML replays with `ui.run_scenario`.
7. Events: `ui.events` `{}` returns `latest`; invoke `Send` on an open Request; `ui.events` `{"since": <latest>, "kinds": ["run"], "wait_ms": 10000}` returns when the run finishes.
8. Read `docs/agent-testing.md` for the `.mcp.json` snippets, tool catalog and playbook; in Claude Code the `ui-test` skill (`.claude/skills/ui-test`) performs steps 1 to 5 and reports defects.
