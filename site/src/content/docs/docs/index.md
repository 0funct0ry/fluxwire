Fluxwire is a native client for REST and WebSocket APIs. A request is a `.flux.md` file in your repository: Markdown
that reads as documentation on GitHub and that Fluxwire, the command line, and AI agents can all execute.

## Start here

- [Install](./getting-started/install/) Fluxwire on macOS, Linux, or Windows.
- Follow the [Quick start](./getting-started/quick-start/) to send your first request in a few minutes.
- Learn how a [Collection](./getting-started/first-collection/) is laid out on disk.
